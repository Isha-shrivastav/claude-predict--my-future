# claude-predict--my-future
AI-powered Vedic astrology infographic generator that transforms birth details into a clean, modern prediction report using prompt engineering. Features a minimal violet-themed design with Lagna Chart, Wealth, Health, and Career Opportunity insights. Built as a prompt engineering and AI design experiment for Claude and other LLMs.# 🔮 Claude Predict My Future

An AI-powered Vedic astrology infographic generator created using prompt engineering with Claude.

- AI-generated astrology infographic
- Minimal violet-themed design
- Vedic Lagna (Rashi) Chart
- Wealth Prediction
